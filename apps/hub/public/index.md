# Idle — a browser and YouTube Playables game lab

Idle is a parked research project for learning how idle mechanics, reusable HTML5 game infrastructure, and portable distribution work in practice.

## Play the retained game

[Idle Startup](https://idle.aliveville.com/play/idle-startup/) is the working result. Ship features, hire a team, raise rounds, accumulate offline progress, and continue without an account.

## What the lab produced

The shared gamekit owns the simulation loop, versioned saves, offline progress, pause behavior, platform adapters, and build boundaries. The same game ships as a normal browser experience and a submission-ready YouTube Playable package.

## Current state

The research goal is complete and the project is parked. There is no promised next game; it reopens only for a specific mechanic worth studying.
